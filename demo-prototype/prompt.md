## Creating a Wireframe – with a tool for wireframes.
Design a modern, two-column login wireframe screen with the following structure and elements: Left column: Large image
Right column: Login form, vertically centered
Form Elements (Right Column): Title: “Login” with a Description about the app
Email address: Text input with a place holder and a nice icon with a validation message about validating email structure.
Password input field with a place holder and icon and also show password
Submit button: Labeled “Log in” — full width
line separator below the form
Below the line separator add Text links “Forgot your password?” and “Change password”


## Creating a Responsive Login Page – with a tool for creating code.
Create a responsive login page using Bootstrap 5 with custom HTML and CSS (no JavaScript or backend).
The layout should follow the provided wireframe and consist of a two-column design: an image section on the left and a login form on the right.
Use the following color scheme: #11151C as the primary background, #212D40 for secondary surfaces, and #364156 for accents or borders.
The page must be fully responsive, meaning that on medium and larger screens, both columns are visible side by side,
but on small screens and mobile devices, the image section should be hidden, and only the login form should be displayed,
taking up the full width. The login form should include fields for email and password, a “Remember me” checkbox, a “Forgot password?” link,
and a primary submit button. Ensure proper spacing, clear typography, semantic HTML structure, and accessibility features such as labels and sufficient color contrast.
Use a placeholder image for the left section if none is provided and make sure the form is vertically centered on larger screens.
